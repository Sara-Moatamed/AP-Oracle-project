# Oracle Accounts Payable Cycle Project

This project demonstrates the full **Accounts Payable (AP)** cycle in **Oracle ERP**. It covers the entire process from supplier creation to payment processing and GL reconciliation. The steps include:

- **Creating Suppliers**: Set up supplier profiles and manage supplier data.
- **Bank Account Setup**: Configure bank accounts for payment processing.
- **Invoice Entry & Approval**: Input and validate supplier invoices.
- **Payment Processing**: Process payments to suppliers based on approved invoices.
- **Clearing**: Match payments with invoices and clear outstanding items.
- **Period Closing**: Perform necessary closing tasks for the AP module.
- **General Ledger Posting**: Post the completed transactions to the General Ledger for final reporting.

This project reflects practical experience with **Oracle Financials**, demonstrating the real-world implementation of an Accounts Payable cycle in an ERP system. The goal is to showcase how **Oracle ERP** automates and manages the full lifecycle of accounts payable processes, ensuring accuracy and efficiency in financial operations.
